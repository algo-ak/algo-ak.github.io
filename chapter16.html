Chapter 16

NP-Completeness

Suppose you have a bag with a weight limit and want to pack items worth at least 90. If someone hands you a list of items, you can add up their weights and profits to check it. How quickly can you find such a list yourself? That difference between solving and checking is at the heart of P versus NP.

16.1Decision and optimization problems

The same set of items can give rise to two questions. In both cases, the bag holds at most 16 units of weight, and each item can be taken once.

Decision

Can we pack items with a total profit of at least 90? The answer is YES or NO.

Optimization

What is the largest total profit we can pack? The answer gives the best value, and may include the chosen items.

P and NP classify decision problems. In Chapter 17, we use the same example to find the maximum profit.

16.2Polynomial and exponential growth

In this chapter, an algorithm is efficient if its worst-case time is bounded by a fixed polynomial in the length of its input. For example, when n is the number of items, doubling n multiplies n² by 4. A search over every subset has 2n choices. Each new item doubles that count.

These counts describe particular algorithms. The P versus NP question asks whether better algorithms exist for all problems in NP.

16.3P and NP

PA deterministic algorithm can answer the decision question in polynomial time. For example, scan a list to decide whether it contains a given number.
NPEvery YES instance has a short piece of evidence, called a certificate, that a deterministic algorithm can verify in polynomial time. For a NO instance, every proposed certificate fails the check.

For the knapsack decision problem, the certificate is a subset of items. Items 1 and 3 weigh 2 + 10 = 12 and earn 40 + 50 = 90. Both limits are met, so this subset proves the answer is YES. If a proposed subset fails either check, another subset could still succeed.

Every problem in P is also in NP (P ⊆ NP). A verifier for a problem in P can simply run the polynomial-time solver and use its answer.

P versus NPDoes every decision problem with quickly checkable YES certificates also have a polynomial-time solver? This remains open. NP stands for nondeterministic polynomial time. Clay Mathematics Institute

16.4What makes a problem NP-complete?

An NP-complete problem meets both conditions.

  1. In NP. We can check a YES certificate in polynomial time.
  2. NP-hard. We can translate every problem in NP into it in polynomial time while preserving the YES or NO answer. This translation is called a reduction.

A polynomial-time solver for even one NP-complete problem would solve every problem in NP in polynomial time. For each problem, first translate the input, then run that solver. This would prove P = NP.

16.53-SAT and its certificate

3-SAT asks whether some assignment of true or false to the variables makes a formula true. A literal is a variable such as x or its negation ¬x. In the example, each clause has three literals joined by OR (∨), and the clauses are joined by AND (∧). Each clause needs at least one true literal, and every clause must pass.

Check a 3-SAT assignment

Start with all variables set to 0 (false). Switch x to 1 (true) and see which clause fails. Then switch z to 1 and see what changes.

¬x ∨ y ∨ z1 ∨ 0 ∨ 0 = 1
x ∨ ¬y ∨ w0 ∨ 1 ∨ 0 = 1
¬z ∨ u ∨ v1 ∨ 0 ∨ 0 = 1
All three clauses are true. This assignment proves the answer is YES.

The assignment is the certificate. Checking it takes one pass through the clauses, which shows that 3-SAT is in NP.

Why 3-SAT is NP-complete

The Cook–Levin theorem shows that SAT, the general satisfiability problem, is NP-complete. SAT can be reduced to 3-SAT in polynomial time. So every problem in NP can first be translated to SAT, then to 3-SAT.

16.6Polynomial-time reductions

A ≤p B means we can turn any input of A into an input of B in polynomial time. The two inputs must have the same answer. A solver for B can then answer the original question about A.

Reduce Subset Sum to 0/1 knapsack

Use Step to translate the example and check why the answer stays the same.

Start with the Subset Sum instance. Each number can be used at most once.
Subset Sum (A) Can we choose a subset of {2, 3, 7} whose sum is exactly 5?
→
0/1 knapsack decision (B) Give each number an item with that weight and profit. Can we pack weight ≤ 5 and earn profit ≥ 5?

For any target T, set both the bag capacity and profit target to T. Since every item has equal weight and profit, a subset satisfies both limits exactly when its sum is T. Making one item per number takes polynomial time. MIT lecture notes on the reduction

Direction of the proofStart with a known NP-complete problem A and reduce it to your target B to prove B is NP-hard. Subset Sum is A here. We already checked that 0/1 knapsack decision is in NP, so the reduction proves it is NP-complete.

16.8NP-hard problems

A problem is NP-hard if every problem in NP can be reduced to it in polynomial time. A polynomial-time solver for an NP-hard problem would therefore give a polynomial-time solver for every problem in NP.

Decision and optimization problems can both be NP-hard

Consider the Travelling Salesman Problem (TSP). A tour visits each city exactly once and returns to the starting city.

Decision version · NP-complete

Is there a tour with total cost at most 100? The answer is YES or NO. In the general decision problem, the cost limit is part of the input.

Optimization version · NP-hard

Find a tour with the lowest possible total cost. The answer is a tour.

If you can find a cheapest tour, compare its cost with the given limit to answer the decision question. This shows why the optimization version is also NP-hard. The same idea works for 0/1 knapsack by comparing the maximum profit with the target. Stanford TSP notes

An NP-hard decision problem can be outside NP

The Halting Problem asks whether a given program eventually stops on a given input. It has a YES or NO answer, and it is undecidable. Every problem in NP is decidable by exhaustively checking all certificates up to the polynomial length bound, so the Halting Problem is outside NP.

To see why it is NP-hard, take any SAT formula and construct a program that tries all truth assignments. The program halts if it finds a satisfying assignment and runs forever if it exhausts the assignments. The SAT answer is YES exactly when the constructed program halts. Writing the program with the formula embedded takes polynomial time, even though running it may take much longer. Swarthmore notes on SAT and NP-hardness

NP-hardness alone gives no guarantee of efficient verification

The Non-Halting Problem is the complement of the Halting Problem. Given a program and an input, it asks whether the program runs forever on that input.

To reduce SAT to Non-Halting, construct a program that tries all truth assignments. This time, the program runs forever if it finds a satisfying assignment and halts if it exhausts the assignments. Writing this program also takes polynomial time. The SAT answer is YES exactly when the constructed program runs forever, so Non-Halting is NP-hard.

Could a finite certificate always prove the claim “This program will never stop”? There is no general algorithm that can verify such certificates for all true non-halting claims, even with unlimited time to check each certificate. So polynomial-time verification of YES instances is impossible here. Cornell notes on the limits of computability

Why would a verifier for Non-Halting decide Halting?

Suppose every true non-halting claim had a finite certificate that an algorithm could check, and the checker rejected every certificate for a program that halts. Run two tasks in parallel. Simulate the given program, and search all finite certificates using the checker. The simulation finishes if the program halts. The search finds an accepted certificate if the program runs forever. One task must succeed, so together they would decide the Halting Problem. That contradicts its undecidability.

Self-check. If B is in NP and B reduces to 3-SAT, is B NP-complete?

The reduction shows how a solver for 3-SAT could solve B. To prove that B is NP-hard, reduce a known NP-complete problem to B. Then combine that result with B being in NP.
